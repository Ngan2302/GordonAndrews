# GordonAndrews
Assignment 3
For this last assignment, my topic is recreating my website prototype about Gordon Andrews by html and css. Compared to the prototype process, making a responsive website is by far harder by not just the amount of work but also requires a good understanding about coding. For the basic css code, most of them are for text, font and background colour styling, which takes an important part in my styling concept. Because of the overwhelming amount of pages, the final website would only have seven pages: homepage, about, catalogues, mockup, banknotes and signage. Although having too many pages would make the styling steps become difficult, creating detailed navigation helps investigating the website become easier. The most important css element in the website is the grid column system, which not just helps create the website layout but also for image resizing. The grid not just helps separating the content but also creates the uniqueness in the website layout. 
However, the hardest part is the breakpoint, which is not just about screen size change but also layout changing. To make the site responsive, I decided to change the spread navigation to burger navigation. Because of the large amount of headline, a burger navigation would be more suitable. The ‘read more’ button also helps reduce the image size in mobile versions.The tablet version does not need much changing because of the small screen size change. In tablet screens, the navigation turns into two lines instead of one, but still does not affect the site layout and response much.  
However, although the desktop prototype has been recreated quite the same, the mobile version is not as successful. Because of the grid system being too complex with too much class, the clashing of code made the changing of the h2 and h3 text ineffective. As h2 and h3 in screen size changed, some homepage and about page images could not be seen, which brought the inconsistency.  With the using a three column grid in the desktop version, it would be hard to change it into a two column grid. Despite text and aligning code has been used, because the image, content and footer is highly affected.
Because the use of grid and column take an important part in recreating the prototype, both fixing or deleting it would still be a hard choice. The website might not be successfully responsive, css system still takes an important part in the website stylizing, from the change of background colour to the breakpoint navigation and button styling. The website might not successfully break as planned but still partly responsive.
This project does not just give me more knowledge and experience in coding but helps me understand the working of a responsive website. The project also helps me to understand choosing a simple layout and also helps bring the website’s effectiveness. By knowing the working of breakpoint, my next design could be minimised for easy to control but also suitable for different screen sizes. Although the result of my website could not be said as successful, it still successfully brings the vintage but minimalistic style of Gordon Andrew.
